# Entrega del TFM

El documento de Proyecto Final M0645 pide README, código en GitHub, presentación y vídeo con explicación y captura de pantalla. Recomienda un despliegue. El correo del 15/10 distingue el plazo de corrección en un mes y el plazo FUNDAE, con los detalles registrados en el inventario del máster.

| Elemento            | Estado                                                                                                                                                                      |
| ------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Demo local          | `npm run demo:tfm` genera tres cuentas y una base ficticia en memoria.                                                                                                      |
| Tarifas e IA        | PDF de prueba recorrido en navegador. La oferta de compra se aprueba por separado del precio de venta. Se comprobó el recálculo y, en API, el respaldo cuando Ollama falla. |
| Operaciones         | Anulación de recepción vinculada, baja de devoluciones dañadas y resultados documentales de reclamaciones cubiertos por pruebas dirigidas.                                  |
| Código y README     | Candidato local para GitHub. Se excluyen bases, capturas históricas, secretos, cachés y dependencias instaladas.                                                            |
| Presentación        | Siete diapositivas actualizadas en la presentación de la conversación.                                                                                                      |
| Vídeo               | [Guion de grabación](guia-demostracion.md) con recorrido y tiempos. Pendiente de grabar con la explicación del alumno.                                                      |
| GitHub y despliegue | Pendientes de elegir destino y visibilidad. La demo funciona localmente.                                                                                                    |

La demo de defensa es independiente del escenario mensual. Para usar `start-month-scenario.cmd` se requiere un escenario local generado previamente. El paquete de código prescinde de esos datos y de las cuentas de trabajo.
